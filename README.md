# Hi there, I'm Jager 👋

Welcome to my GitHub profile! 我是 **Jager**，这里记录我的前端项目、编程练习与计算机基础学习。

我的项目主要围绕 **React 与 TypeScript** 展开，同时也在积累 **C/C++、算法、操作系统、计算机网络和数学建模** 的知识。从一个概念的独立示例，到包含路由、状态管理和数据交互的应用，我希望把每一步学习都留下可阅读、可运行的记录。

## 🚀 About Me

### My Approach to Learning 🌱

**用项目验证理解，用笔记整理思路。**

学习一个新概念时，我喜欢先写一个小示例，观察它的行为，再把它放进更完整的项目中。我的仓库既有音乐应用、记账应用等项目练习，也有围绕 Hooks、组件通信、渲染优化和状态管理的专题示例。

### What I'm Exploring 🔍

- **Frontend Development** — 使用 React 和 TypeScript 组织界面，练习组件拆分、页面路由、状态管理与样式设计。
- **React in Depth** — 通过独立仓库梳理 Hooks、依赖项、副作用清理、状态提升、ref 与 memo 等机制。
- **Computer Science Fundamentals** — 从 C 语言的数组与指针出发，逐步理解内存、线程、数据结构和网络通信。
- **Algorithms & Problem Solving** — 整理动态规划、背包、字符串等题型，在代码与题解之间建立联系。
- **Mathematical Modeling** — 学习如何把实际问题转化为模型，再通过算法与计算工具分析和求解。

### What You'll Find Here 📚

这里既是我的项目展示页，也是学习资料的入口。你可以浏览应用代码、查看专题练习，或者沿着笔记了解我如何拆解问题、理解概念和记录实践过程。
